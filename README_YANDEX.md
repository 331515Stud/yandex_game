## 🚀 Шаги для публикации:

### 1. Подготовка файлов
```bash
# Создать иконки (можно использовать генераторы):
- icon-192.png (192x192 пикселей)
- icon-512.png (512x512 пикселей)

# Сделать скриншоты:
- Запустить игру в браузере
- Сделать 3-5 скриншотов разных моментов геймплея
- Сохранить в формате PNG/JPG
```

### 2. Регистрация в консоли разработчика
1. Перейти на https://games.yandex.ru/console/
2. Войти через Яндекс ID
3. Нажать "Добавить приложение"
4. Заполнить информацию:
   - Название: "NEEDLE.IO — Арена выживания"
   - Описание: "Динамичная арена выживания с прокачкой навыков..."
   - Категория: "Экшен" или "Аркады"
   - Язык: Русский

### 3. Загрузка файлов
1. Создать ZIP-архив с файлами:
   ```
   needle-io.zip
   ├── index.html
   ├── game.js
   ├── style.css
   ├── sdk.js
   ├── manifest.json
   ├── icon-192.png
   └── icon-512.png
   ```
2. Загрузить архив в консоль разработчика
3. Указать главную страницу: `index.html`

### 4. Настройка монетизации
В консоли разработчика:
1. Раздел "Монетизация"
2. Включить:
   - ✅ Межстраничная реклама
   - ✅ Вознаграждаемая реклама
   - ✅ Баннерная реклама (опционально)
3. Настроить частоту показа рекламы

### 5. Тестирование
1. Использовать режим тестирования в консоли
2. Проверить:
   - Запуск игры
   - Работу рекламы
   - Отображение на мобильных устройствах
   - Сохранение прогресса

### 6. Публикация
1. Пройти модерацию (обычно 1-3 дня)
2. После одобрения игра появится в каталоге
3. Мониторить статистику в консоли

## 💰 Монетизация:

### Типы рекламы в игре:
1. **Межстраничная (Interstitial)** — при проигрыше
2. **Вознаграждаемая (Rewarded)** — за возрождение и бонусы
3. **Баннерная** — в меню и паузе

### Рекомендации по доходам:
- Не злоупотреблять рекламой
- Давать игроку выбор (возрождение за просмотр)
- Баланс между рекламой и геймплеем

```javascript
ysdk.Adv.showFullscreenAdv();

ysdk.features.GameplayAPI.stop();
```
